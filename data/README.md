# data/

Input data shipped with the repository (about 64 MB). Locations can be redirected with `KIDSPIPE_DATA` (everything), `KIDSPIPE_OFFICIAL` (the KiDS-Legacy release files) and
`KIDSPIPE_EMULATOR` (the emulator artefact); see the table in the top-level [README.md](../README.md). The DR5 shear catalogue (16.4 GB) is **not** here: it is downloaded
from the public KiDS server (see the end of this file).

## Contents

| path | what it is | source |
|---|---|---|
| `kv450/xipm_data_vector.dat` | KV450 xi+/- data vector (15 tomographic pairs, 9 angular bins; the likelihood cuts it to 195 points) | KV450 public cosmic-shear data (Hildebrandt et al. 2020), as distributed in the KiDS kcap repository (`data/KV450`); renamed copy, the original provenance header was not kept |
| `kv450/cov_analytic.txt` | analytic 270 x 270 covariance matrix of the KV450 xi+/- data vector | same (kcap `data/KV450/covariance/cov_analytic_montepython_mcorr.txt`, renamed) |
| `kv450/c_term_treecorr.out` | additive-bias (c-term) measurement | same |
| `kv450/nofz/` | KV450 DIR redshift distributions `Nz_DIR_z*.asc` (5 tomographic bins) and the shift covariance `DIR_cov.asc` | same |
| `cosebis/COSEBIs_En_nModes20.fits` | KV450 COSEBIs E_n data (15 pairs x 20 modes), covariance, n(z) | KV450 public data, as distributed in kcap (`data/KV450/combined`) |
| `cosebis/Tplus_minus/`, `cosebis/roots_norms/` | tabulated COSEBIs filter functions T_+n, T_-n (0.5-100 arcmin) and the roots / normalisations of the log-weight polynomials (0.5-100 and 0.5-300 arcmin) | COSEBIs filter tables (`TLogsRootsAndNorms`, `Tplus_minus` of the COSEBIs code used by kcap), copied from the kcap tree; the roots / norms can be regenerated with mpmath (`docs/interface_notes/cosebis.md`) |
| `cosebis/cache/` | **regenerable cache**: W_n(l) operators computed by `kidspipe.theory.cosebis` (`W_*.npz`, 5.4 MB, two files shipped) | generated by this code; delete for a clean tree, it is rebuilt on first use (about 10-20 s per table) and written back when the directory is writable |
| `kids_legacy/KiDS_Legacy_xipm.fits`, `KiDS_Legacy_cosebis.fits` | official KiDS-Legacy cosmic-shear data vectors, covariances and n(z) (xi+/-, COSEBIs) | KiDS-Legacy cosmic shear data release (`data/` folder of the tarball); byte-identical copies |
| `kids_legacy/cosmosis_xipm/XI_KiDS_Legacy_NScomb_nBins_6_Bin{i}_Bin{j}.ascii` | the official TreeCorr xi+/- measurements per tomographic pair (21 files), used for the DR5 comparison | same release (`data/cosmosis_xipm/`); byte-identical |
| `kids_legacy/Nz_covariance.txt`, `RELEASE_README.txt` | redshift-shift covariance and the release README (citation and acknowledgement text) | same release (`data/Nz_covariance.txt`, `README.txt`); byte-identical |
| `kids_legacy/official_cosebis/` | the official fiducial COSEBIs chain `output_nautilus_cosebis_Fiducial.txt` (15 MB) and the CosmoSIS `pipeline.ini`, `priors.ini`, `values.ini` (stored here as `KiDS_Legacy_cosebis_pipeline.ini` etc.) | same release (`chains_and_config_files/cosebis/`); identical content. The bandpower, xi+/- and external-probe chains of the release (about 250 MB) are not shipped |
| `validation/anchors_test_cosmology.json` | regression anchors (sigma8, Omega_m, S8, C_ell, xi, chi2 at the spec test cosmology) | produced by this project's reference implementation of the spec (`docs/MASTER_MATH_SPEC.md`); our own |
| `validation/k_h.txt`, `z.txt`, `pk_mead.txt` | stored CAMB 'mead' non-linear P(k, z) used to test the stand-alone HMcode | kcap `tests/test_pofk/camb_output` |
| `validation/pofk_values.ini`, `flinc_theory_vector.ascii` | cosmology of that P(k) test; theory vector of the Flinc mock cosmology | kcap test files |
| `emulator/transfer_emulator_v1.npz` | PCA + polynomial / Gaussian-process emulator of the CAMB linear transfer function for (omch2, ombh2, h), trained on 1435 CAMB runs (10 MB) | **our own**, produced by `scripts/train_emulator.py` (README, "Architecture" and `docs/PERFORMANCE.md` section 6); validation in `runs/validate_emulator_pipeline*.json` |

The row "source" entries for `kv450/`, `cosebis/` and `validation/` describe the origin as recorded in `docs/VALIDATION_TARGETS.md` and `docs/REVIEW.md`; the copies were
renamed, and the original release file names and checksums were not all kept. Where exact provenance matters, compare with the public KV450 / kcap files.

## Not shipped: the DR5 shear catalogue

| item | value |
|---|---|
| file | `KiDS_Legacy_NS_unblind_final.fits` (single binary table in extension 1, 40,894,394 rows, 16,398,671,040 bytes) |
| download (gzip, about 7.2 GB) | <https://kids.strw.leidenuniv.nl/DR5/data_files/KiDS_Legacy_NS_unblind_final.fits.gz> |
| KiDS DR5 weak-lensing page (column description, terms) | <https://kids.strw.leidenuniv.nl/DR5/legacy_wl.php> |
| KiDS-Legacy cosmic-shear data release (131 MB tarball; only needed if you want files beyond those shipped here) | <https://kids.strw.leidenuniv.nl/sci_data/KiDS_Legacy_cosmic_shear_data_release.tar.gz> |
| default location | `~/kids_dr5_work/` (`KIDSPIPE_DR5_CATALOGUE`, `KIDSPIPE_DR5_WORK`); the extract `bin0.npz` .. `bin5.npz` (about 1.6 GB) is written next to it |

The URLs are also constants in `src/kidspipe/paths.py` (`CATALOGUE_URL`, `RELEASE_URL`). `scripts/dr5_chain.py` (see [scripts/README.md](../scripts/README.md)) and `notebooks/03_dr5_measurement.ipynb` download and unpack the catalogue.

## Acknowledgement and citation (KiDS)

The KiDS-Legacy / DR5 data and the data products derived from them are used under the conditions set by the KiDS collaboration: **acknowledge KiDS and cite the KiDS DR5 data release paper,
Wright et al. 2024 (A&A 686, A170), and the KiDS-Legacy papers listed in the release README**. The full, authoritative statement (including the funding acknowledgement) is on
<https://kids.strw.leidenuniv.nl/DR5/legacy_wl.php>; it is not reproduced here.

The release README (`kids_legacy/RELEASE_README.txt`) asks to cite:

* Wright et al. 2025 (A&A, 686, A170): KiDS DR5 data release paper (the release README prints the year as 2025; the volume of A&A 686 dates from 2024)
* Wright et al. 2025 (A&A, 703, A158): KiDS-Legacy cosmic shear analysis
* Stölzner et al. 2025 (A&A, 702, A169): KiDS-Legacy consistency and joint constraints with external probes
* Reischke et al. 2025 (A&A, 699, A124): KiDS-Legacy covariance
* Wright et al. 2025 (A&A, 703, A144): KiDS-Legacy redshift calibration

and to include in publications: "Based on observations made with ESO Telescopes at the La Silla Paranal Observatory under programme IDs 179.A-2004, 177.A-3016, 177.A-3017, 177.A-3018, 298.A-5015."

For the KV450 products (`kv450/`, `cosebis/COSEBIs_En_nModes20.fits`) cite Hildebrandt et al. 2020 (A&A 633, A69) and the other KV450 papers named on the KiDS data pages.
